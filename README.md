# Delta Hulk Panel

This project contains a Roblox script that creates a Delta Hulk Panel with a Hulk face button. When the button is clicked, it reveals two action buttons: "Thunder Clap" and "Ground Smash". The script includes animations for both actions and flings nearby players when the actions are performed.

## Install

1. Download the `src/DeltaHulkPanel.lua` file from the GitHub repository.
2. Place the `DeltaHulkPanel.lua` script in the `StarterPlayerScripts` folder in your Roblox game.

## Use

1. Run the game.
2. Interact with the Delta Hulk Panel by clicking the Hulk face button.
3. Click the "Thunder Clap" or "Ground Smash" buttons to perform the respective actions.
